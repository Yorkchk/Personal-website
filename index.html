About

I study Computer Engineering at the University of Ottawa, where I started in September 2023. My work starts with data: collecting it from messy sources, checking and cleaning it, and organizing it so people can trust it and use it.

From there I build the backend services and REST APIs that make the data useful to other people and applications, mostly with Python, FastAPI and Spring Boot, and I deploy them to the cloud. I've done this at work in Python and Pandas, and on my own projects with PySpark, Delta Lake and Microsoft Azure.

I like projects where I own the whole path, from the first meeting about what's needed to the tool someone finally uses.

Personal project · Data platform

Bitcoin Data Platform

An end-to-end data platform that I designed and run on my own Azure subscription. It ingests Bitcoin market data from the CoinGecko API, refines it through a medallion lakehouse on Azure Databricks, models it as a star schema, and serves it through a rate-limited, Redis-cached REST API and a React dashboard.

  • Loads new data every day and processes only what's new.
  • Organizes the data into clean tables built for analysis.
  • Shares it through a public dashboard and an API with free keys.
  • Runs in Docker containers on Azure.
